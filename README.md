# Ahead story reels
45–60 s English 9:16 money stories (hot news first, then history), opening on a hook card, drawn in code (three.js low-poly world, Kokoro narrator, synthesized music), checked, then posted to Instagram @ahead.learn.
- `setup.sh` once per workspace · `trends/insights.md` = retention per episode (`insights.py`) · `new_episode.sh NNN-slug` · work in `episodes/NNN-slug` · `render_full.sh` · `finish.sh name` · `host_video.sh` → vidIQ import → publish → `clear_media.sh`.
- `template/` is episode 1 (Mansa Musa, 1324) and the reference for every new episode. `episodes.json` is the log; `ideas.md` the backlog.
- Branch `media` only ever holds the one video being posted.
